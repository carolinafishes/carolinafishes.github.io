The Black Tide Ritual

What it does

This chart gives the crew one brutal look at the whole run. It can read a ready-made CSV or cut a labeled travel-notes file into Pirate Map rows before plotting the haul.

How to use it

Upload either a Pirate Map CSV or a travel-notes text file, raise the chart, click a mark to inspect the damage, then use the day and category filters to cut the voyage down to size. If the source was notes, claim the forged CSV when you're ready.

Expected CSV

Required: latitude, longitude, popup.

Optional: title, html, category, type, day, reviews, rating, reviewCount, featured.

Expected notes

The text parser looks for labeled blocks like Location, Name, Description, Image links, Keywords, Type of place, Day, Links to reviews, Ratings, and Reviewer counts.
